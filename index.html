System Purpose

One platform for the whole traffic lifecycle

PTM monitors roads through smart cameras and IoT devices, detects vehicles and motorcycles, reads number plates, identifies configured violations, secures evidence, manages penalties and gives authorised officers real-time access.

End-to-end workflow

From detection to case closed

Every verified event follows the same auditable path. Uncertain AI predictions are always routed to a human verifier before any enforcement action is taken.

IoT & Embedded Layer

C-programmed edge devices,
cloud-grade intelligence

Road-side units run a lean C/C++ firmware that captures frames, reads radar and inductive-loop sensors, pre-filters motion, then publishes over MQTT to the PTM server where the heavy AI pipeline runs. This keeps bandwidth low and lets a camera keep operating if the network drops.

Security & Governance

Built for accountable enforcement

Human-in-the-loop by design. PTM never issues a penalty from an unverified AI prediction alone. Detections below the configured confidence threshold are marked PENDING VERIFICATION and require an authorised officer to review the evidence before a case is opened. Every evidence view is written to the audit log.
